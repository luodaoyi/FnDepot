# Asura FnDepot

飞牛 fnOS 第三方应用源。

## 添加仓库源

在支持 FnDepot 的第三方商店中添加：

```text
https://github.com/luodaoyi/FnDepot
```

如客户端要求填写 JSON 直链，使用：

```text
https://raw.githubusercontent.com/luodaoyi/FnDepot/main/fnpack.json
```
